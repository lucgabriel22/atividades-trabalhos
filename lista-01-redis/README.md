# Lista 01 — Redis

Resolução comentada de 20 exercícios sobre estruturas de dados e operações do
Redis. Os comandos estão em [`respostas.md`](respostas.md).

Execute cada bloco separadamente no `redis-cli`. Alguns exercícios dependem do
estado criado pelos anteriores.

> **Atenção:** o exercício 20 usa `FLUSHDB`, que apaga todas as chaves do banco
> Redis selecionado. Use apenas em um ambiente local e descartável.
